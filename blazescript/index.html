BlazeScript

Domains: Compilers LLVM

This project is a custom programming language whose compiler is made from scratch that uses ahead of time compilation which offers real advantages over JavaScript for certain workloads on the web. The end goal being is to genrate a web assembly object file that is faster than javascript on certail workloads

Benchmark

The above benchmark shows that the web assembly is 1.09x times faster than legacy javascript.

Approach & Workflow

  1. Lexical Analysis (Lexer)

    Raw source code text is broken down into structured tokens, identifying keywords, identifiers, and operators.

  2. Syntax Analysis (Parser)

    Tokens are organized into an Abstract Syntax Tree (AST), enforcing the grammatical rules of the language.

  3. Code Generation (LLVM IR)

    The AST is traversed to generate LLVM Intermediate Representation (IR), which is hardware-independent.

  4. Optimization & Wasm Compilation

    LLVM optimizes the IR and compiles it down to a highly efficient WebAssembly binary object file.

Key Concepts

Ahead-of-Time (AOT) Compilation

Unlike JavaScript's Just-In-Time (JIT) compilation, BlazeScript compiles code entirely before execution. This eliminates runtime parsing and optimization overhead, leading to faster and more predictable startup times.

WebAssembly Targeting

The compiler ultimately generates a WebAssembly (Wasm) object file. Wasm is a low-level binary format that runs at near-native speed in modern browsers, making it ideal for heavy computational workloads.

Custom Compiler Pipeline

Built entirely from scratch, the pipeline involves lexical analysis, parsing into an Abstract Syntax Tree (AST), and custom code generation. This provides deep insights into language design and fine-grained control over performance.
