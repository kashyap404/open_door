AmazeDex

Domains: Reinforcement Learning Dexterous Manipulation MuJoCo

AmazeDex is a reinforcement learning project focused on autonomous in-hand dexterous manipulation using a 4-fingered Amazing Hand by Pollen Robotics. The system trains control policies in MuJoCo simulation to reorient a cube to target poses, using visual tracking to deploy the learned movements onto real hardware.
